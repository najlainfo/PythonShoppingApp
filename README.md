# App de Compras (Proyecto Python)

**Descripción del Proyecto**
Aplicación de simulación de compras y gestión de pedidos. Desarrollada íntegramente en Python, enfocada en estructurar una lógica de negocio sólida, escalable y orientada a la experiencia del usuario.

**Tecnologías Utilizadas**
* Python
* Lógica de negocio

**Objetivo**
Diseñar un sistema estable para el manejo de inventario y simulación de transacciones comerciales de forma ágil.
